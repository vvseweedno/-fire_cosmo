# Third-Party License Register

This register is a release checklist, not a claim that all optional resources
are bundled.

| Component | Use | License/provenance status |
|---|---|---|
| NumPy | numerical arrays | verify installed distribution license at release |
| Rasterio/GDAL | GeoTIFF IO and CRS metadata | verify installed distribution and GDAL license notices |
| FastAPI/Starlette/Uvicorn | REST service | verify installed distribution licenses |
| Pytest/httpx/Ruff | development and CI | development-only; verify distribution licenses |
| Synthetic demo GeoJSON | offline service demo | authored in this repository; no external data |

No pretrained model, external fire product, OSM tile, WorldCover asset, or
private-test-derived resource is included in the current release package.
When one is added, record its exact version, source URL, license, access date,
and allowed competition use before promotion.
