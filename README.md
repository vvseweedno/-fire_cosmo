# Wildfire Nexus Core

**Оперативный мониторинг лесных пожаров на данных ДЗЗ**

## 📋 Соответствие заданию хакатона

Сервис реализует **двухэтапный анализ**:

### Этап 1: Поиск очагов горения
- **Источники:** MODIS, VIIRS, Landsat (тепловые каналы)
- **Фильтрация:** отсев ложных срабатываний (промзоны, вода, низкая уверенность)
- **Результат:** список верифицированных очагов с координатами

### Этап 2: Картирование гарей
- **Источник:** Sentinel-2 (мультиспектральные каналы)
- **Метод:** NBR/dNBR индексы для оценки степени поражения
- **Результат:** полигоны гарей с классификацией и площадью в гектарах

## Быстрый старт

### Требования

- Docker 24+
- Docker Compose 2.20+

### Запуск

```bash
git clone https://github.com/vvseweedno/-fire_cosmo.git
cd -fire_cosmo
cp .env.example .env
docker compose up --build
```

Откройте http://localhost:8000

## API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/health` | Проверка здоровья |
| GET | `/api/v1/fires` | Список очагов (GeoJSON) |
| POST | `/api/v1/fires/analyze` | Анализ региона |
| GET | `/api/v1/events/{id}` | Детали события |
| GET | `/api/v1/events/{id}/burned.geojson` | Полигон гари |

## Валидация

```bash
python scripts/validate_two_stages.py
```

Ожидаемый вывод:
```
ЭТАП 1: Поиск очагов горения
- MODIS: 150 точек
- VIIRS: 200 точек
- Landsat: 5 сцен
- После фильтрации: 280 точек (отсеяно 20%)

ЭТАП 2: Картирование гарей
- NBR pre: min=0.123, max=0.567
- dNBR: min=0.05, max=0.45
- Площадь: 125.5 га
```
