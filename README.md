# Wildfire Nexus Core

**Оперативный мониторинг лесных пожаров на данных ДЗЗ**

## 📋 Соответствие заданию хакатона

Сервис реализует **двухэтапный анализ** в строгом соответствии с заданием:

### Этап 1: Поиск очагов горения
- ✅ **Источники:** MODIS (1 км), VIIRS (375 м), Landsat (100 м тепловой)
- ✅ **Отсев ложных срабатываний:** 6 фильтров (координаты, confidence, промзоны, вода, облака, термические пороги)
- ✅ **Результат:** верифицированные очаги с координатами

### Этап 2: Картирование гарей
- ✅ **Источник:** Sentinel-2 (10-20 м, мультиспектр)
- ✅ **Метод:** NBR/dNBR + классификация по 4 классам severity
- ✅ **Результат:** полигоны гарей + площадь в гектарах

### Итоговый результат
- ✅ Веб-сервис (FastAPI + Leaflet)
- ✅ API endpoints для получения данных
- ✅ Карта с отображением очагов и гарей
- ✅ Справка о площади гари в гектарах

## 🚀 Быстрый старт

### Требования

- Docker 24+
- Docker Compose 2.20+

### Запуск

```bash
git clone https://github.com/vvseweedno/-fire_cosmo.git
cd -fire_cosmo
cp .env.example .env
docker compose up --build
```

Откройте http://localhost:8000

## 🔌 API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/health` | Проверка здоровья |
| GET | `/api/v1/fires` | Список очагов (GeoJSON) |
| POST | `/api/v1/fires/analyze` | Анализ региона |
| GET | `/api/v1/events` | Список событий |
| GET | `/api/v1/events/{id}` | Детали события |
| GET | `/api/v1/events/{id}/burned.geojson` | Полигон гари |
